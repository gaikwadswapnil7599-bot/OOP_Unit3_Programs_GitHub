This repository contains 16 C++ programs covering the core concepts of polymorphism as part of the Unit 3 practicals.

## Overview

The programs demonstrate:

- Function overloading
- Operator overloading
- Virtual functions and runtime polymorphism
- Abstract classes and pure virtual functions
- Object slicing and destructor behavior
- Mini real-world applications using polymorphism

## How to Compile and Run

To compile and run a program, use:

```bash
g++ -std=c++17 program1.cpp -o program1
./program1
```

For any other program, replace `program1.cpp` with the desired file name, for example:

```bash
g++ -std=c++17 program2.cpp -o program2
./program2
```

## Requirements

- C++ compiler such as `g++`
- Standard: `C++17`
- Linux, Windows, or macOS terminal

## Notes

- Each program is independent and can be compiled separately.
