# OOP with C++ - Unit 3: Polymorphism

16 C++ programs from the Unit 3 Polymorphism practical code book.

## Programs
| Sr. No. | Folder     | File Name       | Description                                                                                                        |
| :-----: | :--------- | :-------------- | :----------------------------------------------------------------------------------------------------------------- |
|    1    | Program_01 | `program01.cpp` | **Function Overloading:** Demonstrates multiple functions with the same name but different parameters.             |
|    2    | Program_02 | `program02.cpp` | **Area Calculator using Function Overloading:** Calculates the area of a square, rectangle, and circle.            |
|    3    | Program_03 | `program03.cpp` | **Unary Minus Operator Overloading:** Overloads the unary minus operator to negate an object's value.              |
|    4    | Program_04 | `program04.cpp` | **Prefix and Postfix Increment Operator Overloading:** Demonstrates both prefix and postfix increment operators.   |
|    5    | Program_05 | `program05.cpp` | **Binary + Operator Overloading:** Adds two complex numbers using the overloaded `+` operator.                     |
|    6    | Program_06 | `program06.cpp` | **Relational Operator Overloading:** Compares two objects using the overloaded relational operator.                |
|    7    | Program_07 | `program07.cpp` | **Friend/Non-member Operator Overloading:** Uses a friend function to overload the `+` operator.                   |
|    8    | Program_08 | `program08.cpp` | **Base Pointer Without Virtual Function:** Demonstrates function calling through a base-class pointer.             |
|    9    | Program_09 | `program09.cpp` | **Base Pointer With Virtual Function:** Demonstrates runtime polymorphism using a base pointer.                    |
|    10   | Program_10 | `program10.cpp` | **Base Reference With Virtual Function:** Demonstrates polymorphism using a base-class reference.                  |
|    11   | Program_11 | `program11.cpp` | **Abstract Class and Pure Virtual Function:** Demonstrates an abstract class with a pure virtual function.         |
|    12   | Program_12 | `program12.cpp` | **Collection of Polymorphic Shape Pointers:** Stores different shape objects using polymorphic pointers.           |
|    13   | Program_13 | `program13.cpp` | **Virtual Destructor:** Demonstrates proper destruction through a base-class pointer.                              |
|    14   | Program_14 | `program14.cpp` | **Object Slicing Demonstration:** Shows the difference between passing a derived object by value and by reference. |
|    15   | Program_15 | `program15.cpp` | **Payment Processing System:** Demonstrates a payment processing system using polymorphism.                        |
|    16   | Program_16 | `program16.cpp` | **Employee Payroll Mini-Project:** Calculates and manages employee payroll information.                            |


## Compile
g++ -std=c++17 program1.cpp -o program1
./program1

The same pattern can be used for program2.cpp through program16.cpp.
